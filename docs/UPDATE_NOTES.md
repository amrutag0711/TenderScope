# TenderScope updated version

This release includes 850 **synthetic** procurement examples. The dates, organizations, descriptions, prices and categories are generated for demonstrations, not extracted from CPPP or GeM. Never use these examples for procurement decisions.

## Screenshot guidance
Capture Overview, Data Collection, Preprocessing, Demand Analytics, Trends, Association Rules, Similarity, Clustering, Search, Value Analysis, Reports and Evaluation after running locally. Do not fabricate screenshots.

## Limitations
No automatic live portal collection. Similarity is textual, not legal duplicate detection. Lift greater than one indicates positive co-occurrence only. Trend counts are observational.
