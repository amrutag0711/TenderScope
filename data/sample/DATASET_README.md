# Synthetic demonstration dataset
720 entirely generated records; NOT genuine government procurement notices. Generated with deterministic random seed 17. Publishing dates span 2023 through 2026 based on generated calendar offsets. Includes 12 Indian states and 8 product categories. `source_portal` is `SYNTHETIC DEMO`; `source_url` is blank. Every 13th record has a missing estimated value. No external collection occurred. `collected_at` is a generation label, not a government retrieval timestamp. Fields follow the 20-column schema in `config.py`. Currency values represent hypothetical INR estimates. This dataset is suitable for software demonstration, not empirical policy or procurement conclusions.
